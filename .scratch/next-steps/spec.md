# Private Beta MVP Roadmap

Generated by the improve skill on 2026-08-23 against commit `a96ce03` and the
current working tree. Execute in order unless dependencies say otherwise.

## Beta product contract

The first private beta is deliberately narrow:

- Windows 11 (Windows 10 is best-effort until separately exercised).
- A user can pair one RomM server, sync a library, browse it in desktop or
  immersive mode, press Play once, and return after the emulator exits.
- The certified emulator is RetroArch for NES, SNES, GB, GBC, GBA, and Genesis.
- Manual save upload/download is supported. Automatic save sync is not promised
  until a real pre/post-launch round trip is certified.
- Standard-mapped/XInput controllers are supported for immersive navigation and
  the certified RetroArch path. Other controllers are best-effort.
- All other emulators, platforms, shaders, achievements, and expanded controller
  shortcuts are experimental and do not block beta.

## Beta-ready definition

Do not invite testers until all of these are true:

- A repository and release origin controlled by the new maintainer publishes a
  signed beta installer and updater manifest.
- Pair → sync → Finish → restart preserves the RomM session and the BIOS page can
  still use it.
- A large catalogue does not load or validate every game on each desktop or
  immersive refresh.
- No usable RomM access token is written to `config.toml`.
- A Wingosy-managed RetroArch install uses the pinned frontend/core manifest and
  a repairable Wingosy delta without overwriting a user's main configuration.
- Immersive input ignores unknown controller mappings, survives disconnect and
  reconnect, identifies actions without assuming Xbox button labels, and exposes
  a bounded persisted stick deadzone with a `0.35` reset default. Unsupported
  pads are best-effort; keyboard input and a standard/XInput controller are the
  recovery path, while gameplay binding repairs belong in RetroArch's
  **Input → RetroPad Binds → Port 1 → Set All Controls → Save Controller Profile**.
- The six promised RetroArch combinations have real Windows 11 evidence, and at
  least one permitted game has completed remote first Play, cached replay,
  controller/fullscreen return, and a save round trip.
- A clean install and an update preserve configuration, database, and ROM paths.
- Testers know the supported scope, log location, feedback route, and data backup
  expectation.

## Findings considered and rejected

- Certifying every advertised emulator before beta: rejected; one emulator
  family gives a coherent beta with far fewer runtime permutations.
- Standalone mGBA in the beta promise: deferred; it duplicates GB/GBC/GBA coverage
  already provided by RetroArch.
- Automatic save sync as a launch promise: deferred until a real round trip is
  verified; incorrect save claims risk user data.
- Background emulator updates, custom image caching, shaders, achievements, and
  more controller shortcuts: not worth doing before the core loop survives a cohort.
- Steam Input templates, a controller remapping UI, controller profile packs,
  haptics, and radial menus: deferred; native RetroArch autoconfig plus one reset
  path covers the private-beta recovery case.
- Crash telemetry or an external analytics service: rejected for MVP; local logs
  and an explicit feedback route are sufficient for a private cohort.
